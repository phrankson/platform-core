# platform-core documentation

This documentation follows the [Diátaxis](https://diataxis.fr/) framework.
Each section serves a different purpose — pick based on what you're trying
to do right now.

| I want to... | Go to |
|---|---|
| Get this project running for the first time | [Tutorials](tutorials/getting-started.md) |
| Do a specific task (deploy, add an environment, run tests) | [How-to guides](how-to/) |
| Look up an exact config field, function signature, or pipeline detail | [Reference](reference/) |
| Understand why this is built the way it is | [Explanation](explanation/architecture-and-design-choices.md) |

This is separate from [`learning/`](../learning/README.md), which is a
narrative, analogy-driven walkthrough written for one specific reader
learning platform engineering. This directory assumes general engineering
competence and no prior context on this specific project.
